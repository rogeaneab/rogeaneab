A solução: uma plataforma com trilhas de aprendizagem, exercícios com execução de código real no navegador, feedback imediato e elementos de gamificação.

Meu papel: concepção, pesquisa com o público-alvo, levantamento de requisitos, desenvolvimento do front-end e deploy.
